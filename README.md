# fuxx-dev Homebrew tap

Homebrew formulae for the [fuxx](https://github.com/fuxx-dev) family of tools.

```sh
brew install fuxx-dev/tap/fuxx-completes
```

| Formula | What it is |
| --- | --- |
| `fuxx-completes` | [fuxx-autosuggestions](https://github.com/fuxx-dev/fuxx-completes): grey suggestions in zsh and bash from your own history and your project's commands. macOS 11+, Apple Silicon and Intel. |

After installing, `brew info fuxx-completes` shows the one line to add for your shell.
